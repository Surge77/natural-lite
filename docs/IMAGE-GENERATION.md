# Image-generation brief

The lifestyle assets were created with the built-in image-generation workflow.
The old screenshot crops and the full-page reference supplied composition,
subjects, color, and mood. The pouch JPEGs supplied product identity.

## Shared direction

- Use case: photorealistic-natural, precise-object-edit, or compositing.
- Intended use: Natural Lite ecommerce homepage photography.
- Style: warm, documentary-leaning editorial photography with realistic skin,
  fabric, food, paper, metal, and wood texture.
- Palette: warm cream, forest green, muted burgundy, turmeric gold, and pale wood.
- Lighting: soft diffused morning light; clean neutral light for processing and
  laboratory scenes.
- Constraints: no overlay text, standalone logos, watermarks, borders, rounded
  corners, extra people, extra products, malformed hands, or duplicated objects.
